# FORGE v0.8 Windows VST3

- Windows x64 VST3 + Standalone target for REAPER.
- Full dark/green FORGE UI with Capture, Perfect Lead, Build Stack, Neural and Export pages.
- Auto key/scale analysis with heavy-music profiles.
- Rough/scream protection for low-confidence non-tonal events.
- Natural PSOLA pitch correction preserving motion/vibrato.
- Heavy-vocal Mix Assist.
- Scale-degree doubles, harmonies and octave reference stack.
- Per-instance session state and REAPER stack import helper.
- Windows CI packages the offline engine, validates the VST3 with pluginval and builds an installer.
